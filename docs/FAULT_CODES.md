# Fault codes

Generated by `ESP32/tests/generate_fault_codes.py`; do not edit codes here.

Codes are stable hexadecimal identifiers, independent of enum ordering. For combined interlocks, the lowest defined bit selects the primary code; the full mask is retained and decoded. Unknown bits are displayed explicitly.

`0302` means stale data or invalid timestamp ordering. Records retain decision time, snapshot time/sequence, raw unsigned age, timeout, validity, previous state and actual mode. A future age is marked INVALID, never clamped or accepted.

Serial: `FAULT?` reads the latched first cause; `FAULT HISTORY` reads the 32-entry overwrite history; `FAULT DETAIL` prints the captured full snapshot on demand if it still matches that episode. Default output is one compact line per fault transition. Emergency-stop escalation appends an event without replacing the first cause. RESET archives the episode; it does not authorize START.

Wire: `FAULT seq=... t=... code=0302 detail=0002 prev=2 mode=1 tick=... age=... timeout=100 safety_seq=... flags=... reason=9`. `prev` follows the existing state enum; mode 1 is MANUAL, 0 AUTO. Flag bit 0 means safety valid; bit 1 means the unsigned age is in the valid half-range. All other numeric fields are decimal except code/detail (hexadecimal). The ring and latch are RAM-only and reset at boot.
